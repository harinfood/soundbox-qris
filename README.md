# Soundbox QRIS

Aplikasi Android yang membacakan nominal pembayaran ShopeePay lewat NotificationListenerService dan Text-to-Speech.

## Cara build di GitHub
1. Buat repository baru, lalu upload seluruh isi folder ini.
2. Buka tab Actions dan tunggu workflow "Build APK" selesai.
3. Unduh artifact `soundbox-qris-debug`, lalu pasang `app-debug.apk` di HP.
4. Buka aplikasi, tekan "Buka Izin Akses Notifikasi", dan aktifkan "Soundbox QRIS".

Pastikan TTS Bahasa Indonesia sudah terpasang di HP.
